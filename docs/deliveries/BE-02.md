## Public interface and contract

```python
from tennis_backend.media import inspect_media, MediaLimits, MediaError

manifest = inspect_media(local_path, limits=MediaLimits())
```

`inspect_media(path, *, limits=None) -> dict` returns exactly the frozen
MediaManifest fields. It has no dependency on `tennis_backend.contracts` and
requires only Python's standard library plus the installed `ffprobe` executable.
The head must perform cross-branch Pydantic validation/integration separately.
No requested dependency or contract changes.

`MediaLimits` is an immutable dataclass. Positive integer ceilings reject bools;
time/duration ceilings must be finite and positive. Defaults:

| Ceiling | Default | Enforcement |
|---|---:|---|
| `max_bytes` | 536,870,912 (512 MiB) | stat before inspection and bounded hash reads |
| `max_duration_seconds` | 600 | known selected-stream/container durations and observed min/max PTS span |
| `max_frames` | 36,000 | reject the first additional frame while parsing stdout |
| `timeout_seconds` | 30 | one monotonic deadline across hash, container walk and all subprocesses |
| `max_output_bytes` | 8,388,608 (8 MiB) | aggregate stdout + stderr, including version/metadata/frames |

The output reader requests at most the remaining budget plus one byte, detects
overflow before storing/parsing the chunk, then kills and reaps the child. Both
pipes are drained with selectors; stderr is discarded. Any native error output
at `-v error` rejects the inspection even if FFprobe exits zero. Native calls use
argument arrays, `shell=False`, closed stdin, single decoder thread, 64 MiB
maximum individual native allocation, bounded probe size and analysis duration.
Failures never return partial successful manifests.

`MediaError.code` and `.to_dict()` provide the frozen ErrorEnvelope, with empty
`details`, generic messages and no private path or native stderr. Codes include
`invalid_path`, `file_unavailable`, `invalid_media`, `unsupported_container`,
`external_reference`, `container_limit`, `byte_limit`, `duration_limit`,
`frame_limit`, `output_limit`, `timeout`, `file_changed`, `tool_unavailable`,
`invalid_tool_output`, `no_video_stream` and `no_video_frames`. Invalid caller
limits raise `ValueError` (or `TypeError` for an unrelated limits object).

## Selection, timestamps and source preservation

- Select `V:0`: the first video stream excluding attached pictures. Audio and
  later video streams do not populate the timeline. A cover-only asset fails.
- Frames follow FFprobe's decoded presentation order. Use only original frame
  `pts` and the selected stream's exact rational `time_base`. Preserve offsets,
  irregular intervals, missing PTS (`null`) and non-increasing PTS. Stable
  reasons are `missing_pts` and `nonmonotonic_pts`; no FPS substitution,
  best-effort timestamps, interpolation or image-duplicate detection.
- Record native SAR and rotation; unavailable or conflicting rotation is null.
  Dimensions prefer positive/nonzero FFprobe `coded_width`/`coded_height`, with
  encoded stream `width`/`height` as the metadata fallback when coded fields are
  absent/zero (common for FFV1). No display correction or coordinate transform.
- Duration prefers selected-stream metadata, then container metadata, and can
  remain null. FPS values are descriptive native metadata or null. They never
  establish temporal resolution or unique information per frame.
- Hold the input descriptor read-only. Reject a final path symlink, directory,
  FIFO, URL/protocol path, empty input or unsupported container. Pass the held
  descriptor via `/dev/fd`, not a mutable pathname, to FFprobe. SHA256 covers the
  complete accepted file. Compare device/inode/size/mtime_ns/ctime_ns on the
  descriptor AND pathname after inspection, including native failure paths.
  Changed, replaced or removed files reject with `file_changed`. Reads can update
  filesystem access time; no write, copy or transcode is performed by inspection.

## Local-format restrictions and remaining protection limits

Detect container signatures and force `mov`, `matroska` or `avi`; whitelist
`mov,matroska,webm,avi` and only the `file` protocol. Playlists/indirect formats
are rejected regardless of filename. MOV external dref URLs, URNs and aliases,
reference-movie atoms, and Matroska inter-segment links are rejected before the
native process; MOV also explicitly disables external drefs/absolute aliases.
Compressed MOV headers and unknown-size EBML elements other than Segment are
unsupported. Container walks have depth/element-count/time ceilings and skip
payload using declared lengths. This deliberately excludes some otherwise
playable files. Known whole-container duration also enforces the duration ceiling,
so a long non-selected track or offset-inclusive container duration may reject.

These controls restrict ordinary supported decoder/demuxer behavior; they are
**not an OS security sandbox or a proof that an arbitrary hostile file is safe**.
The native FFprobe binary runs with the current user's privileges. `file` protocol
permission is needed for the held descriptor; an exploited native binary is not
prevented from accessing other local files or making system calls. No hard total
RSS/address-space limit, CPU quota or filesystem/network isolation is installed;
`max_alloc` is per allocation, not aggregate memory. The wall deadline uses polling
and kill/reap and cannot promise an interruptible deadline for stalled kernel I/O.
Use a separate OS sandbox/container before accepting untrusted remote uploads.

Duration metadata may be absent or inaccurate. Only known metadata and observed
PTS span can enforce duration; missing timestamps remain inspectable as required,
so this module cannot establish their true elapsed recording time. Frame/byte/
output/deadline ceilings still apply. Decoder success does not authenticate media,
prove corruption absence, detect every repeated image or establish scientific
validity. Stat checks detect ordinary concurrent changes, not a privileged actor
able to defeat OS metadata guarantees. This implementation uses POSIX APIs and
`/dev/fd`; Windows support is not claimed.
