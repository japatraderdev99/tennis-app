## Delivered interface

```python
from tennis_backend.selection import select_target

selection = select_target(
    artifact,
    seed_frame_index=12,
    seed_detection_id="explicit_frame_local_id",
    min_iou=0.2,
    ambiguity_margin=0.05,
)
```

The input is the full neutral PoseArtifact dictionary, never an unbound frame
list. The return includes its exact `asset_id` and original `time_base`, schema
`0.1.0`, method `conservative_iou_v0`, seed, parameters, all source frame indices
and PTS, and `validation_ref=null`. This follows the head's updated authoritative
`docs/P2_POSE_LAB.md`, consulted read-only after its interface correction. The
initial contract copy in this builder checkout still shows the old frames-only
signature; shared documentation was not edited here.

Strict independent Pydantic validation covers the complete artifact: unknown or
missing fields, schema and provenance, finite JSON parameters, hashes, positive
rational time_base, dimensions, monotonic integer frame indices/PTS, frame-local
unique detection IDs, positive-area finite boxes, ordered COCO17 points, paired
nullable coordinates, model-native scores, and visibility/presence bounds.
Input errors raise `ValueError` (including Pydantic `ValidationError`); absent
seed never falls back to another person. Thresholds reject booleans/coercion;
`min_iou` is in `(0,1]` and margin in `[0,1]`.

## Association behavior

- Before the seed: `not_started / before_seed`.
- At the seed: exactly the requested detection, regardless of size/position.
- Consecutive source frames: IoU against the last selected box. IDs may change
  across frames and are never treated as identity evidence.
- Best IoU below threshold: `lost / iou_below_threshold`.
- No detections: `lost / no_detections`.
- Source frame gap after seed: `lost / frame_gap`.
- Runner-up within inclusive ambiguity margin: `ambiguous / ambiguous_iou`.
  A runner-up just below min_iou still counts conservatively.
- Every later frame after an interruption: `lost / reseed_required`. Resuming
  requires a new call with a new explicit seed.

Only selected frames have non-null detection IDs and null reasons; other frames
have null detection IDs and nonempty snake_case reasons. No interpolation,
clamping, reidentification, face processing, FPS-derived timestamps or automatic
recovery. All frames, including pre-seed/post-loss evidence, are validated before
return. Inputs are not modified.

IoU areas use exact rational arithmetic on validated float coordinates to avoid
overflow/underflow for extreme finite geometry. Only final IoU and score-gap
comparisons round to float precision, preserving ordinary decimal threshold
boundaries such as IoU=0.2 and margin=0.05.

## Limits and integration

No interface deviations from the head's corrected P2 contract. No imports from
the unmerged pose module or optional inference libraries. No real media, real
landmarks, model files, scientific research edits or shared dependencies enter
this delivery. No merge, push or deploy performed.

`selected` means heuristic geometric association, not verified athlete identity.
IoU cannot rule out an identity switch during an unobserved/nonambiguous crossing
or a detector error. Human target confirmation remains necessary; these synthetic
tests establish implementation behavior only. No score, ideal-angle threshold,
coaching, scientific validation or public metric release is implemented.

Head review, CV/DS integration and private real-video inference checks remain
pending and are separate acceptance steps. Full-artifact validation materializes
frames in memory, and exact IoU arithmetic is not benchmarked for live throughput.
