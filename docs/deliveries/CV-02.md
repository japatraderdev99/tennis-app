## Behavior and interfaces

`infer(image_bgr, *, frame_index, pts, time_base)` returns a plain JSON-compatible
PoseFrame dictionary. Images must expose a nonempty uint8 HxWx3 buffer (including
NumPy uint8 arrays); malformed shape, dtype or coercible nested Python lists fail.
Each adapter is sequential, belongs to one timeline, and requires increasing
original frame indices and PTS with constant display size/time-base value.
Sampling gaps stay explicit. IMAGE mode permits independent sparse samples with
colliding API milliseconds; original indices/PTS still increase.

MediaPipe maps indices `[0,2,5,7,8,11,12,13,14,15,16,23,24,25,26,27,28]` to
COCO17, scales normalized x/y separately by display width/height, preserves
visibility and presence, and emits null score. Its bbox spans all finite source
landmarks; absent/degenerate geometry fails explicitly. Coordinates outside the
image remain unchanged. VIDEO computes exact `round(pts * Fraction(time_base) *
1000)` (nearest millisecond, ties to even) only for the native API. Collision or
backwards time fails before that native call; returned PTS is never replaced.

RTMPose uses local YOLOX boxes, skips pose inference entirely for zero boxes, and
validates box geometry before any pose crop. It requires exactly 17 native COCO
points per box, preserves finite native scores including values outside [0,1],
and emits null visibility/presence. IDs are per-frame ordinals, not identities.
Neither adapter filters detections into an automatically selected athlete.

`provenance()` returns a defensive plain dictionary with adapter/runtime versions,
CPU delegate/provider metadata, local weight SHA256 values, explicit parameters
and mapping/transforms. It contains no model paths or download URLs. Weight file
stat changes during hashing/initialization cause failure. Hashes establish the
local bytes, not independent upstream authenticity or model licensing.

`close()` is idempotent and final; context management is supported. All available
resource closers are attempted even if one fails. RTMLib/ORT sessions have no
explicit native close method, so backend references are released. Native failures
consume the submitted timestamp because a tracker may already have advanced.
Malformed data/weights/timing raise ValueError (including Pydantic validation
errors); missing optional imports raise explicit ImportError; inference after
close raises RuntimeError.

## Limits and pending head checks

No interface deviations from CV-02 P2. Consulted the head's updated definitive P2
document; its selection/evaluation changes do not alter this adapter interface.
No shared files, dependencies, videos or exploratory scripts were changed.
No merge, push, deploy, model downloads or real-model inference were performed.

Head must provision optional packages/weights, verify installed API/checkpoint
compatibility, perform private real-video checks and join frames to MediaManifest.
The adapter only knows the supplied corrected display plane; the head must add
original-to-display transforms. These adapters are not thread safe and do not
recover a failed inference by retrying its timestamp. Concurrent external weight
replacement is unsupported; initialization checks detect ordinary file changes.

Model keypoint score is not calibrated probability or uncertainty. Passing
synthetic tests establishes implementation behavior, not athlete accuracy,
identity, biomechanical validity, licensing clearance or scientific acceptance.
`validation_ref` remains null and `measurement_status` remains `research_only`.
No public metric, M01 computation, quality score, ideal angle, training, injury
claim or coaching is released by this module.
